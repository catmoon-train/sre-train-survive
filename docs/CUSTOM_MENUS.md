# 游戏内自定义菜单编辑器

服务端原版箱子与铁砧 GUI，客户端不用安装模组。沿用 `config/habi_train_survive/menus.json`，旧菜单配置兼容，不必删除重建。

## 入口与权限

- 管理员：`/menu edit` 或 `/menueditor`。管理中心 `/habi` 和默认管理菜单也有“自定义菜单编辑器”入口。
- 直接编辑某页：`/menu edit <菜单ID>`。
- 玩家目录：`/menus`、`/menu list`，只显示自己有权限打开的菜单。
- 打开菜单：`/menu <ID>` 或 `/menu open <ID>`；ID与保留子命令同名时使用后者。
- 取消私密文本录入：`/menu cancel`。
- 手动修改文件后重载：`/menu reload`。重载后旧草稿必须放弃并重新打开，不能覆盖新配置。

编辑器要求原版 **OP 2**；含控制台指令的整份菜单配置只有 **OP 4** 可以保存。控制台指令类型也仅向 OP 4 提供编辑入口。自定义权限组的 `habi.admin` 不代替这里的原版 OP 检查。

## 新建一套菜单

1. `/menu edit` →“新建自定义菜单”，输入唯一 ID，例如 `server_tools`。ID为1～64位小写字母、数字、下划线或短横线，全局最多128页。
2. 设置显示标题、1～6行、打开权限及返回页。新菜单自带一个关闭按钮。
3. 进入“编辑按钮与布局”，点击空格新增按钮，再设置图标、名称、说明与点击动作。
4. 使用“安全预览”检查实际槽位和图标数量；预览不执行指令、不收费、不传送。点击已有按钮回到编辑；Esc关闭后仍可用 `/menu edit` 恢复草稿。
5. 点击“保存全部草稿”。所有校验通过后写入配置并立即生效，通常无需重启。
6. 玩家使用 `/menus` 或 `/menu open server_tools` 打开。也可以在主菜单添加一个 OPEN 动作，指向该菜单。

所有界面中的编辑先进入个人草稿，关闭 GUI 后仍保留，**离线或停服会清除未保存草稿**。主页“放弃草稿”需要确认，只恢复当前有效配置，不写文件。保存按钮一次保存本草稿内所有菜单的修改，而非只保存当前页面。

## 可编辑内容

### 菜单

- 新建、复制整个菜单；自定义菜单还可重命名ID或删除。
- 标题（支持 `&` 颜色）、行数、打开权限、返回页。
- 默认菜单、Shift+F快捷键开关、自动补齐系统入口开关。
- 静态菜单与世界/家/地标/城镇/在线交易玩家等自动列表类型。

内置 `main/worlds/homes/warps/towns/players/admin` 的ID不允许改名/删除，避免破坏代码入口；其标题、权限和可编辑布局仍可修改。自动列表的内容来自对应系统，不允许手工摆按钮；切换静态类型后可以自行布局。把已有手工布局切换成自动列表会先确认清空此页按钮。

缩小菜单时，如果有按钮超出新范围会拒绝缩小，必须先移动或删除，不会偷偷丢按钮。自定义菜单改名会更新 OPEN、返回页和默认页引用；被引用或作为默认页的菜单不能直接删除。

### 按钮与装饰

- 点击真实背包物品或输入物品ID选择图标，只复制材质，不消耗物品。
- 名称、图标数量1～64、打开所需权限。
- 最多32行说明：新增、编辑、上移、下移、删除。
- 移动和独立复制到其它空格，不覆盖已有按钮。
- 使用主手材质（空手默认黑玻璃）填充边框或所有空槽，只处理原本为空的位置。
- 装饰按钮选择“仅展示”，不会执行动作或发送空白聊天。

布局编辑页显示槽位1起和行/列坐标；JSON中的槽位从0起。为保留安全页脚，编辑页每页最多45个槽位，第6行需要翻到下一页；运行时仍按原菜单的实际6行布局显示。

编辑默认菜单或管理页的按钮布局/动作时，会关闭自动补齐，避免已删改的系统功能重新出现在其它空格。保存后如果确实需要补齐，可以再单独开启该全局选项并保存。

### 点击动作

一个按钮最多16项有序动作，可添加、替换类型、调整顺序、删除并设置每项权限：

| 动作 | 行为 |
| --- | --- |
| 打开其它菜单 | 选择本配置内的目标页 |
| 返回 / 关闭 | 回到菜单设置的返回页，或关闭界面 |
| 玩家指令 | 使用点击玩家本身的权限执行，不提权 |
| 控制台指令 | 使用控制台执行，仅OP4可编辑和保存 |
| 私人消息 | 只发给点击者 |
| 音效 | 输入有效音效ID，调整音量0～4、音调0.5～2 |
| 世界传送 / 随机传送 | 选择已登记世界，继续经过原有安全/费用/读条检查 |
| 仅展示 | 装饰，无实际动作 |

消息和音效可以放在前面；OPEN/BACK/CLOSE、指令或传送必须放最后，因此每个按钮至多一个终止动作。建议子菜单使用 BACK 返回，不要用 OPEN 制造双向循环。非法引用、循环和不合法动作顺序都会拒绝保存，错误说明保留在聊天中，草稿不丢失。

文本占位符：`{player}`、`{uuid}`、`{balance}`、`{world}`、`{online}`、`{group}`、`{homes}`、`{rtp_cooldown}`、`{worlds}`、`{loaded_worlds}`。**指令只接受 `{player}` 与 `{uuid}`**，来自真实账户而非昵称，不把菜单文字作为任意用户指令插入。

控制台动作很强大：只有可信OP4编写；若未配置页面/按钮/动作权限，普通玩家也可以点击执行已授权的静态控制台动作。不要把编辑器向不可信人员开放。

## 普通文字与长文本

普通标题、名称和短指令使用原版铁砧输入框，受原版客户端单次输入长度限制。较长说明/指令可选择“长文本私密聊天输入”：

- 消息由编辑器拦截，不公开到频道；每条追加到缓冲区，不自动插空格。
- 发送 `完成` 提交到草稿、`清空` 重输、`取消` 或 `/menu cancel` 返回；5分钟有效。
- 用 `!` 转义保留词；**指令以 `!` 起头输入，例如 `!/warp spawn`，不要直接发送 `/` 起头的真实指令**。
- 聊天输入为说明提供最多512字，为指令/消息提供最多2048字；同样经过保存时的严格验证。
- 已被服务器禁言的管理员无法使用聊天录入，可用铁砧或解除禁言后录入。
- 权限失效、取消、离线或停服后输入状态清除；重新打开编辑器也会取消未完成聊天录入。

## 文件与冲突保护

保存前检查完整格式、图标/音效存在性、行数/槽位、引用、循环、动作、权限和文件大小。通过后以临时文件原子替换并切换有效配置；失败时保留草稿与旧配置。其他管理员先保存、执行过重载、或外部编辑/删除了配置文件时，旧草稿不能覆盖它们。请先备份文件，再重载有效文件并放弃旧草稿重新编辑。

新增可选JSON字段：顶层 `autoShortcuts`（旧配置默认true），按钮 `amount`（旧按钮默认1）。版本仍为1，GUI保存会显式写出这些字段。
