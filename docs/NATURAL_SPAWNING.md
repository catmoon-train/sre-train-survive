# 主世界自然刷新控制

默认开启：主世界 `minecraft:overworld` 不再自然生成怪物，动物自然生成批次以 50% 概率放行。

## 指令（OP 权限等级 2，支持控制台）

```mcfunction
/worldspawn
/worldspawn true
/worldspawn false
```

依次为查看状态、开启限制、关闭限制。切换立即生效并保存，重启保留。关闭是恢复原版刷新规则，不会强制打开 `doMobSpawning`，也不会改变服务器难度。

## 配置

首次启动自动生成 `config/habi_train_survive/natural_spawning.json`：

```json
{
  "enabled": true
}
```

手动编辑后执行 `/habi reload`。配置无效时保留当前有效规则，原文件不会被默认值覆盖；指令保存失败时不会切换内存中的规则。

## 范围

- 仅限制主世界，不影响下界、末地、主城或其他自定义维度。
- 阻止普通自然怪物刷新、幻翼、掠夺者巡逻队和僵尸围城。
- 陆地、水生与环境动物的自然刷新按批次减半，覆盖新区块动物生成及村庄/沼泽小屋猫的自然生成。
- 这是刷新机会的概率折减，不是删除一半现有动物，也不是保证实际生物数量恰好减少 50%；原版生物上限、环境、玩家距离仍然生效。
- 不清理现有生物，不改变刷怪笼、刷怪蛋、指令召唤、动物繁殖、袭击及其他事件触发生成。模组绕开原版自然生成入口的自定义生成也不在此拦截范围内。
- 不修改原版的全局刷怪游戏规则，避免关闭动物生成或影响其他维度。

更新模组 JAR 后需要完整重启一次，以加载新的 Mixin 和生成配置。此后切换指令无需重启。
