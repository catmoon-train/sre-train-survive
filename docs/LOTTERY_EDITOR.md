# 游戏内抽奖管理

## 入口

OP（权限等级 2）执行 `/lottery admin`，或打开 `/lottery` 后点击底部的“管理奖池”命令方块。`/crate admin`、`/gacha admin` 同样可用。普通玩家看不到管理按钮，也无法使用管理命令。

## 操作

- **新增奖池**：点击“新增奖池”，在铁砧顶部输入唯一 ID，点击右侧确认。ID 支持 1–32 位英文、数字、`_`、`-`，自动转小写。默认单抽 200 金币、50 抽保底，初始无奖品。
- **修改奖池**：在奖池页修改名称（支持 `&` 颜色代码）、单抽价格、保底次数。十连价格仍为单抽价格的 9 倍。
- **添加奖品**：点击“添加奖品”，再左键点击下方背包中的物品。复制物品、数量、附魔、名称、Lore 及其他组件，不移动或消耗原物品。初始权重 10、彩金 0、非稀有。
- **编辑奖品**：点击奖品进入详情，可从背包替换完整物品、修改物品名称与数量、权重、附赠金币，或切换稀有大奖。数量不超过该物品的最大堆叠数。要调整附魔、Lore 或其他组件，先在背包中准备好物品，再替换。
- **输入**：在铁砧顶部改文字，点击右侧保存，点击左侧纸张取消；不消耗经验或物品。非法输入在聊天栏提示，可留在输入页继续修改；关闭页面不会保存本次未确认输入。
- **删除**：奖品和奖池都需要二次确认。删除奖池同时清理该池玩家保底，不能撤销；默认奖池删除后不会在重启时自动恢复。
- **分页**：管理列表和玩家预览都有翻页按钮，新增内容不会因首屏容量不足被隐藏。

每次确认修改立即写入 `config/habi_train_survive/lottery.json` 并在内存中生效，不必重启或重载。普通抽奖按权重分配概率；保底从开启“稀有大奖”的奖品中等概率选择，抽到任意稀有大奖会重置该池保底并全服播报。如果没有稀有奖品，保底将无法产出稀有奖励，配置时应至少开启一个。

## 人工验收

1. 用 OP 打开管理页，新建自定义奖池，修改名称、价格和保底；普通玩家无法进入管理。
2. 从背包添加一件有附魔、名称和 Lore 的物品，确认原物品不变；替换、改数量和改名称后抽奖验证奖励组件。
3. 修改权重、彩金和稀有开关，验证预览与实际抽奖；分别测试空值、负数、NaN 和重复 ID。
4. 测试铁砧确认、取消、直接关闭，以及 Shift、数字键、拖动和丢弃，确认界面物品不会被带出或吞掉背包物品。
5. 新增超过 7 个奖池、超过 36 个奖品，检查玩家侧和管理侧分页。
6. 删除奖品和默认奖池，重启后确认修改保留、默认奖池不会恢复；另一名管理员停留旧页面时，应无法编辑或抽取已删除奖池。

自动化校验涵盖编辑参数边界和数据保存/重载，不代替真实客户端点击及视觉验收。
