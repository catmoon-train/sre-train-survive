# 本模组指令帮助

所有玩家都可以使用 `/habi help` 查看本模组指令，无需管理员权限。帮助中展示实际注册的参数形式、别名、功能和所需权限；没有权限的条目仍可查看，不会因此开放执行权限。

## 用法

| 指令 | 功能 |
| --- | --- |
| `/habi help` | 全部指令第1页 |
| `/habi help 2` | 全部指令第2页 |
| `/habi help categories` | 分类目录 |
| `/habi help categories 2` | 分类目录第2页 |
| `/habi help systemshop` | 系统商城指令第1页 |
| `/habi help 商城 2` | 系统商城指令第2页 |
| `/habi help travel` | 传送、家和地标 |
| `/habi help claim` | 领地和地皮 |
| `/habi help admin` | 管理、权限和惩戒 |

支持英文分类ID、常用中文分类名和Tab补全。指令每页6种语法，分类目录每页8类，页码从1开始；非法页码/分类会提示错误，不会绕回或漏项。

## 分类

`general` 综合与菜单、`travel` 传送与家、`world` 世界与主城、`economy` 经济与回收、`systemshop` 系统商城、`playershop` 电子店铺、`chestshop` 箱子商店、`trade` 交易与拍卖、`claim` 领地与地皮、`town` 城镇、`rewards` 礼包与兑换、`lottery` 抽奖、`survival` 任务/墓碑/称号、`social` 聊天与社交、`tools` 随身工具、`admin` 管理与惩戒。

## 安全与权限

- 点击上下页、分类目录或分类按钮，只会执行对应的帮助查询。
- 点击具体指令行仅填入聊天框，不会自动执行、扣费、传送或删除数据。
- 每条显示功能、权限说明及当前“入口权限通过/不足”。“入口通过”不代表满足全部执行条件：领地主人、店主、城镇身份、余额、物品、战斗等继续由原系统验证。
- 权限说明区分原版OP、模组权限节点、权限组与执行时身份限制；控制台也能查看帮助，部分指令本身仅玩家可执行。
- `/habi` 无参数时，普通玩家看到帮助，管理员仍打开管理中心。`habi edit/reload/status/preview` 仍要求 `habi.admin` 或OP2。
- 帮助只捕获本模组注册/替换的执行路径，不把原版或其他模组未改动的指令算作本模组功能。别名和可选参数的不同执行形式可能分列，因此条目数是“语法项”而非指令根数量。

语法与入口权限从实际Brigadier指令树捕获，中文功能/权限说明位于内置 `defaults/command_help.json` 和 `defaults/command_help_cmi.json`。新增指令时应同步说明；开发检查会报告缺少精确说明的路径，避免只更新文档却漏掉真实指令。
